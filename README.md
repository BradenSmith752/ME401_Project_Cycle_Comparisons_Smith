# ME401_Project_Cycle_Comparisons_Smith
This repository documents an engineering analysis of the Otto and Diesel cycles, using gasoline and diesel engines as real world comparisons.
It goes in depth on the ideal and real-world characteristics of both cycles.

The main focus of this analysis is one question: Are gasoline or diesel car engines better for the environment, when comparing their real world data and effectiveness.
This analysis does not go into the process of fuel manufacturing and its effect on the environment.

This project was developed with assistance from AI, for code troubleshooting and final revision.
